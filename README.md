# ERYNDOX

### Cyber Intelligence & Digital Forensics

**Detect • Investigate • Preserve**

ERYNDOX is a cybersecurity and digital forensics platform designed to support security monitoring, threat intelligence, incident investigation, and digital evidence preservation.
